# Changelog

Product updates, newest first. Each entry links to the docs it affects. Channel or feature deprecations are recorded here with dates.

## v0.13

- The client covers the daily product surface: bot setup, [sessions](./sessions.md), providers, channels, workspace files, terminal and desktop panes, [Supermarket](./supermarket.md), [hooks](./hooks.md), [schedules](./schedule.md), [access control](./access.md), and user preferences.
- Interface languages: English, Simplified Chinese, and Japanese.
- Per-bot isolated container workspaces with files, commands, MCP hosting, network access, a headed browser, and a graphical desktop — see [Workspace](./container.md).
- Hooks run automation rules around supported lifecycle events; see the [event catalog](./hooks.md).
- Access control split between channel-side chat permissions and workspace-side member permissions — see [Access Control](./access.md).
